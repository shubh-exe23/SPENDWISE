# 💰 SpendWise – Personal Expense Tracker

SpendWise is a modern Flutter-based personal finance application that helps users track expenses, analyze spending habits, and stay within budget through intuitive visualizations.

Designed with a clean jade-green, fintech-inspired UI, the application provides an elegant experience for managing day-to-day finances.

---

## ✨ Current Features

### 🏠 Home Dashboard

* View current balance, income, and expenses
* Add new income and expense transactions
* Filter transactions by date
* Recent transaction preview
* Clean fintech-inspired UI

### 📜 Transaction History

* Complete transaction history
* Timeline-based filtering
* Organized transaction records

### 📊 Expense Analysis

* Interactive Donut/Pie charts
* Category-wise expense breakdown
* Timeline filters
* Legends and category summaries
* Percentage-based spending insights

---
